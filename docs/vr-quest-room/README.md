## Короткая версия

Игрок оказывается заперт в помещении и за отведённое время решает цепочку из пяти головоломок,
чтобы открыть выход. Перемещение — телепортом, взаимодействие — руками контроллеров.

Ценность проекта для курса создаётся не 3D-контентом, а кодом: конечный автомат комнаты,
граф зависимостей головоломок, событийная шина, инвентарь, система подсказок, сохранение
прогресса и телеметрия прохождения. Вся игровая логика вынесена в обычные C#-классы
без наследования от `MonoBehaviour`, поэтому покрывается юнит-тестами и проверяется
без запуска шлема.

## Отличия прогона от Questa (только в копии для Verilator, код лабы не менялся)

Verilator 5.020 не поддерживает часть конструкций, которые принимает Questa, поэтому `vl_patch.py` в копии:
рандомизация `randomize() with {…}` / `constraint` заменена ручной с теми же диапазонами и весами
(shift 1 : 8 : 1); covergroup заменен счетчиками тех же бинов; добавлен общий непараметризованный
предок секвенсоров; `event … = null` → `event …`; `$stop` → `$finish`; модуль-зеркало сигналов интерфейса
для VCD. Зашифрованный пакет `env_base_chk.svp` (проверки этапов CI) заменен заглушкой. Кодовое
покрытие в отчете (97,18 %) – из CI на Questa, локально не пересчитывалось.
